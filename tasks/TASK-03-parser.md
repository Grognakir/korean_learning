# TASK-03 — Rule-based парсер корейских предложений

Контекст: `tasks/ARCHITECTURE.md`. Зависимости: TASK-02.

## Цель

`src/lib/ko/parse.ts`: разбор предложения о местоположении в `ParsedSentence` либо `ParseError` с русской подсказкой. Контракт `ParseResult` — строго из ARCHITECTURE.md.

## Поддерживаемая грамматика

```
S  → SUBJ LOC 있어요|있습니다|있다 [.|!]?
SUBJ → N(이|가|은|는)
LOC  → REF(의)? POS에            // 학교 앞에, 학교의 앞에
     | REF(하고|과|와) REF 사이에  // 은행하고 약국 사이에
POS  → 앞|뒤|옆|왼쪽|오른쪽|위|아래|밑|안|밖|근처
```

- `N`, `REF` — только слова из `lexemes` (TASK-02), причём параметр `lexemeIds` сужает допустимый набор до сущностей текущей сцены.
- Нормализация: trim, схлопывание пробелов, срез финальной пунктуации. Допускать слитное написание позиции с 에 («앞에») и раздельное («앞 에») не надо — только слитное, но REF может быть написан слитно с частицей («학교가»).

## Требования к реализации

1. Токенизация жадным сопоставлением по словарю: сначала пытаться снять с конца слова частицу (이/가/은/는/의/하고/과/와), потом искать основу в lexicon. Не использовать regex-магию на весь ввод — идти по токенам, чтобы ошибки были точечными.
2. Валидация частиц по 받침 (`hangul.ts`). Неверная частица — это `ParseError` с подсказкой, например: `errorRu: "После «은행» (заканчивается на согласный) нужна частица 이"`, `hintRu: "은행이 …"`.
3. Ошибки должны различаться (каждая — свой `errorRu`):
   - не хангыль / пустой ввод;
   - неизвестное слово (назвать какое);
   - слово не из текущей сцены (назвать какое);
   - нет подлежащего с частицей;
   - нет позиционного слова / нет 에;
   - 사이 без двух ориентиров;
   - нет глагола 있다 в допустимой форме;
   - неверная частица (какая нужна).
4. `relation` маппить через `positionWords`; 아래 и 밑 → `below`.
5. Функция чистая, без состояния; экспортировать также `conjugationForms = ["있어요","있습니다","있다"]` для подсказок в UI.

## Тесты — `src/lib/ko/parse.test.ts`

Минимум:
- ✅ `민수가 학교 앞에 있어요` → subject 민수, front, [학교];
- ✅ `약국은 은행하고 서점 사이에 있습니다` → between, refs [은행, 서점];
- ✅ `가방이 책상 위에 있다`, `고양이…` нет — вместо этого `시계가 문 옆에 있어요`;
- ✅ `유나는 교실 안에 있어요` → inside; `컴퓨터가 책상 위에 있어요.` (с точкой);
- ✅ `민수가 학교의 뒤에 있어요` (с 의);
- ❌ `민수가 학교 앞에` (нет глагола), `민수는 앞에 있어요` (нет ориентира), `민수가 학교 사이에 있어요` (사이 с одним REF), `은행가 학교 옆에 있어요` (частица: нужно 은행이), `banana가 학교 앞에 있어요` (не хангыль/неизвестное слово), слово не из `lexemeIds`.
