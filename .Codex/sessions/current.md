## Принятые решения

- Глобальные стили импортируются один раз в root layout в порядке `reset.css → tokens.css → globals.css → utilities.css`.
- Светлая палитра строится на тёплом бумажном фоне и зелёном акценте; компонентный код должен использовать semantic tokens, а не значения палитры напрямую.
- Созданы все запланированные категории токенов и dark-token scaffold; переключатель темы пока не входит в MVP.
- Глобальный CSS ограничен документными стилями, типографикой, focus/reduced-motion и layout/accessibility utilities; будущие компоненты используют CSS Modules.
- Korean fallback задан через отдельный font token и селектор `[lang="ko"]`.
- Root layout содержит skip-link, а `main` — стабильную цель `#main-content`; минимальный мобильный верхний отступ 64 px оставляет 9,6 px между сфокусированной ссылкой и заголовком.
- Smoke-тест root layout проверяет язык документа и skip-link; CSS imports дополнительно подтверждены production build.
- Браузерная проверка выполнена на 1280×720 и 390×844: горизонтального скролла и console issues нет, responsive typography и focus-ring работают.
- `PLAN_REVISION_2026-08-07.md` остаётся пользовательским неотслеживаемым файлом вне коммитов.
