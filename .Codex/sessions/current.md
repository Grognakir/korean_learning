# Контекст сессии — Korean Learning

Последнее обновление: 2026-08-10

## Чем занимаемся

Исправлены подтверждённые дефекты UI перед продолжением фазы 2: адаптивность, навигация, публичные тексты, учебные экраны, словарь, вход и состояния ошибок. Изменения находятся в ветке `codex/ui-polish-phase-two`.

## Принятые решения

- Нижняя навигация работает до 1024 px и содержит пять учебных разделов: темы, тренировку, повторение, прогресс и словарь; главная остаётся доступна через логотип.
- Мобильные заголовки и верхние отступы уплотнены, максимальный размер H1 ограничен 52 px.
- Последние карточки в нечётных сетках центрируются, а грамматический каталог использует компактные раскрывающиеся уроки.
- Страница урока больше не повторяет заголовок и описание; материалы и тренировки собраны в понятные разделы.
- Из публичного UI удалены внутренние термины и коды; части речи, уроки, сложность и параметры тренировки локализованы.
- Состояние недоступности получило повторную загрузку, пустые состояния и форма входа ограничены по ширине.
