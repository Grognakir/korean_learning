# TASK-08 — Ритм-игра «Слова»

Контекст: `tasks/ARCHITECTURE.md`. Зависимости: TASK-06 (vocab), TASK-07 (вкладка).

## Цель

`src/components/topics/location/RhythmGame.tsx` — вкладка «Слова»: падающие корейские слова, 3 полосы с русскими переводами, клик/клавиши 1-2-3. Без библиотек.

## Механика

- Экраны: старт (правила + кнопка «Начать») → игра → результат («Ещё раз»).
- Поле: 3 вертикальные полосы; внизу каждой — плашка с русским переводом. Сверху по случайной полосе падает корейское слово (`ko-text`, крупно). Одновременно падает **одно** слово (упрощение осознанное — это не осу, а тренажёр).
- Для каждого падающего слова: его перевод случайно ставится на одну из трёх нижних плашек, на две другие — переводы других слов из vocab (дистракторы). Игрок должен нажать полосу с правильным переводом (клик/тап по полосе или клавиши `1`/`2`/`3`) до того, как слово коснётся низа.
- Попадание: слово вспыхивает зелёным (`--ok`), +10 × множитель серии (серия из 5 подряд → ×2, из 10 → ×3). Промах (не та полоса) или слово упало: красная вспышка (`--bad`), −1 жизнь, показать правильный перевод на 800мс. Жизней 3.
- Скорость: начальная ~4с на падение, каждые 5 слов −8%, минимум ~1.5с. Слова берутся из `vocab` перетасованной очередью; очередь кончилась — перетасовать заново.
- Игра до потери жизней ИЛИ 30 слов. Результат: очки, точность %, лучшая серия, список слов с ошибками (корейский + перевод) для повторения.
- Реализация: `requestAnimationFrame` с расчётом позиции от timestamp (не setInterval); пауза при потере фокуса вкладки (`visibilitychange`); cleanup в `useEffect`. Позиция слова — CSS `transform: translateY`.
- Адаптивность: работает мышью и с клавиатуры; на узком экране полосы не схлопываются (мин. ширина плашек, текст переносится).

## Критерии приёмки

- Ручная проверка в `npm run dev`: клавиши и клик работают, попадание/промах/падение считаются верно, жизни и очки корректны, скорость растёт, экран результата показывает ошибочные слова, «Ещё раз» полностью сбрасывает игру, при переключении вкладки браузера игра встаёт на паузу.
- Нет утечек таймеров (переключение вкладок «Задания»/«Слова» туда-обратно не ломает игру).
- `npm run lint`, `npm run build` — зелёные.
