# TASK-10 — Анимация ходьбы персонажа

Контекст: `tasks/ARCHITECTURE.md`, `tasks/TASK-09-pixel-skins.md`. Зависимости: TASK-09 (данные `PersonSprite.walk` уже в манифестах).

## Цель

При перемещении по сцене персонаж разворачивается в сторону движения, играет покадровый walk-цикл, по прибытии встаёт в idle. Работает во всех пиксель-скинах; в `svg`-скине — как раньше (просто transition).

## Что сделать

1. **`src/components/scene/PixelPerson.tsx`** — компонент персонажа внутри `PixelSceneCanvas`:
   - принимает `PersonSprite`, текущую позицию (col/row) и предыдущую (хранить в ref);
   - при изменении позиции: направление = знак Δcol / Δrow (при диагонали приоритет горизонтали); длительность движения = 700ms (как transition);
   - на время движения — CSS-анимация кадров walk выбранного направления: `steps(N)` по `background-position` (кадры лежат в атласе последовательно) либо JS-переключение кадров через `setInterval` ~120ms, если кадры в атласе непоследовательные. Выбери по факту раскладки каждого пака и оставь ОДИН механизм на все скины (JS-переключение проще и универсальнее);
   - по окончании (transitionend или таймер 700ms) — idle-кадр последнего направления;
   - cleanup таймеров при размонтировании.
2. Направления в манифестах: убедиться, что `walk`/`idle` заполнены для всех 4 направлений во всех трёх скинах (Ninja Adventure Walk.png 4×4, Sprout Lands 4 ряда 48×48, LPC universal.png ряды up/left/down/right по 9 кадров — 1-й кадр ряда это стойка, walk — кадры 2–9).
3. Предметы (не person) при перемещении — лёгкий «подпрыгивающий» ход (CSS keyframes translateY ±4px на время движения), чтобы сумка не «скользила».
4. Проверить во всех сценах: command-задания с движением вправо/влево/вверх/вниз (street — горизонталь, building-cut — вертикаль/диагональ).

## Критерии приёмки

- В каждом пиксель-скине: персонаж идёт с анимацией ног в правильную сторону, разворот корректный (влево/вправо не перепутаны), после остановки — idle того же направления, никаких «скользящих статуй».
- Диагональное перемещение (building-cut) не ломает анимацию.
- Быстрые повторные перемещения (два задания подряд) не оставляют залипших таймеров/кадров.
- `npm test`, `npm run lint`, `npm run build` — зелёные.
