# 한글길 — изучение корейского по 급ам

Веб-приложение для тренировки корейского: темы, грамматика и слова.

## Сейчас

- **1급** по структуре 새인하한국어1 (16과)
- Разделы: Темы · Грамматика · Слова
- Anki (SRS в localStorage), подстановка слов, примеры
- Интерфейс на русском

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).
