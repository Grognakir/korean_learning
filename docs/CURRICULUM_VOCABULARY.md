# Канонический словарный корпус курса

Последнее обновление: 2026-08-09

Документ является рабочим словарным источником для приложения и перенесён из `korean-words.md` без сокращения учебных строк.

Формат строки: `한국어 | транскрипция | перевод | заметки`.

Правила дальнейшего импорта:

- одинаковое написание не означает одинаковое значение: омонимы `눈`, `다리`, `만`, `배`, `이`, `저`, `팔`, `풀` должны храниться отдельными значениями;
- повтор одной и той же лексемы с тем же значением объединяется только после сравнения перевода, части речи и заметок;
- названия разделов — учебные категории, а не часть перевода;
- служебное значение `добавлено`, найденное в производных TSV, не является категорией и сюда не переносится;
- этот Markdown является источником корпуса, но публикация конкретной записи требует нормализованного `sense` и статуса проверки в базе данных.

## Неправильные глаголы/прилагательные — ㄷ (ㄷ받침 → ㄹ перед гласной)

Слова из таблиц "Глаголы"/"Прилагательные" выше, собранные отдельно по типу неправильного спряжения — для тренировки конкретно этой закономерности. Правило: ㄷ받침 + гласное окончание (-아요/어요, -았/었어요...) → ㄷ меняется на ㄹ. Перед согласным окончанием (-습니다, -고...) ничего не меняется.

## Неправильные глаголы/прилагательные — ㅡ (выпадение гласной + отдельно 르-неправильные)

Два разных механизма в одной таблице — не путать между собой:

- **Простое ㅡ 탈락** — основа заканчивается на согласную+ㅡ (без받침). Перед -아요/어요 гласная ㅡ просто ВЫПАДАЕТ, смотрим на гласную предыдущего слога (ㅏ/ㅗ → 아요, иначе → 어요). Исключений нет.
- **르-неправильные** — основа заканчивается именно на слог "르" (르받침 нет, это ㄹ+ㅡ). Перед -아요/어요 слог 르 выпадает ЦЕЛИКОМ, а ㄹ удваивается и становится받침 у предыдущего слога, дальше всегда 라/러 (никогда просто 아/어). Это отдельный, более сложный тип неправильности — не то же самое, что простое ㅡ 탈락, хоть внешне слово тоже кончается на "-르다".
