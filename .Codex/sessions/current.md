## Чем занимаемся

Фаза 1 продолжается. Итерации F1-I01–F1-I05 завершены: минимальное приложение, quality/test harness и первые содержательные публичные границы source tree работают.

## Принятые решения

- Проект использует Node.js 24.18.0 LTS и pnpm 10.34.5; проверки выполняются на точном Node.js 24.18.0.
- TypeScript 6.0.3 и ESLint 9.39.2 выбраны как актуальные совместимые ветки; тестовый стек основан на Vitest 4.1.10 и Testing Library.
- Каталоги создаются только вместе с содержательными файлами; пустые placeholders не добавляются.
- Общие сведения о приложении экспортируются через `@/constants`, поддерживаемые языки — через `@/types`, технические функции — через локальную публичную границу `@/lib/utilities`.
- Направление текущих production-импортов: `app → constants → types`; утилиты независимы от предметных и UI-слоёв.
- Простая `classNames` добавлена для будущих CSS Modules и покрыта ближайшим unit-тестом.
- `PLAN_REVISION_2026-08-07.md` остаётся пользовательским неотслеживаемым файлом вне коммитов.
