Контекст: `tasks/ARCHITECTURE.md`. Зависимости: TASK-01…TASK-06.

## Цель

Рабочая вкладка «Задания» на `/levels/1/location`: сцена + задания трёх типов, проверка парсером, анимированное перемещение персонажа, прогресс.

## TaskRunner.tsx (client)

State: индекс задания, рабочая копия сцены текущего задания (deep copy при входе в задание), ввод, статус (`idle | error-parse | wrong | correct`), счёт выполненных.

Раскладка: сцена (`SceneCanvas`) сверху, ниже — карточка задания: `promptRu`, для fix — ошибочное предложение (`ko-text`, зачёркивать не надо), поле ввода (`ko-text`, `lang="ko"`, placeholder `…이 … 앞에 있어요`), кнопка «Проверить» (и Enter), кнопка «Дальше» после успеха, «Показать ответ» после 3 неудачных попыток (показывает один корректный вариант, собранный из lexicon + частица по 받침).

Логика проверки (через `parseLocationSentence`, `holds`, `resolveTargetCell`, `getTrueRelations`):

1. **Ошибка парсинга** → показать `errorRu` + `hintRu` под полем (жёлтый/`--warn`), сцена не меняется.
2. **describe**: `holds(scene, task.subjectId, fact)` и `fact.subjectId === task.subjectId` → верно (зелёная плашка «Верно! ✓» + краткий разбор предложения: субъект/ориентир/отношение по-русски). Истинное, но о другом объекте / ложное → «Предложение грамматично, но неверно по сцене» (`--bad`) с пояснением.
3. **command / fix**: распарсенный факт применяется к сцене: `resolveTargetCell` по написанному → анимированное перемещение субъекта (обновить col/row/containerId в рабочей копии; SceneCanvas анимирует сам). Затем проверка цели: субъект предложения совпадает с `task.subjectId` И на обновлённой сцене `holds(scene', task.subjectId, task.goal) === true` (проверяем результат перемещения, а не совпадение формулировки — если написанное ставит субъекта туда, где цель фактически выполняется, это верный ответ):
   - совпало → «Верно!»;
   - не совпало, но переместить удалось → персонаж уехал не туда; сообщение «Ты написал(а): …по-русски…, а нужно было: …» — наглядная обратная связь через сцену;
   - `resolveTargetCell === null` → «Так в этой сцене встать нельзя», сцена не меняется.
   - для fix при повторении исходной ошибки (`wrongSentence` совпадает с вводом после нормализации) — отдельное сообщение «Это то же самое предложение».
4. Прогресс: «Задание N из M», полоска прогресса; после последнего — экран результата (сколько с первой попытки) и кнопка «Пройти ещё раз» (reset + перемешать задания).

Подсказка-шпаргалка (сворачиваемый блок под полем): список позиционных слов с переводом (из vocab/positionWords) и шаблон предложения.

## Критерии приёмки

- Полный проход всех заданий руками в `npm run dev`: верные и неверные ответы, ошибки частиц дают конкретную русскую подсказку, персонаж плавно едет в описанное место (в т.ч. в неверное при ошибке), fix-задания принимают исправленный вариант.
- Enter отправляет, состояние кнопок корректно, после «Дальше» сцена следующего задания сброшена к исходной.
- `npm run lint`, `npm run build`, `npm test` — зелёные.
