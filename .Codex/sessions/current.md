# Контекст сессии — Korean Learning

Последнее обновление: 2026-08-08

## Чем занимаемся

Завершены F1-I12–F1-I14: после универсальных контрактов модулей и упражнений добавлен локальный репозиторий с валидированным sample-набором. Экран тренировки получает задания через интерфейс репозитория, а не через прямой импорт данных.

## Принятые решения

- Упражнения представлены исчерпывающим union из семи типов с общей версией схемы, сложностью, prompt/explanation и scoring metadata.
- Zod отклоняет неизвестные типы/версии, повторяющиеся options/pairs/topics, неверные correct refs, неоднозначные matching pairs и некорректные blank markers.
- Sample-набор содержит 14 упражнений: по два задания каждого типа.
- `LocalExerciseRepository` валидирует каждое задание при регистрации и проверяет уникальность id/logical version, module/topic refs и поддержку типа модулем.
- `ExerciseRepository` предоставляет `getById` и фильтруемый `list` по модулю, темам, типам и сложности.
- Общий feature-слой не импортирует sample-контент; композиция module registry и exercise repository находится в `src/modules/registry.ts`.
- Экран `/training` показывает фактическое число доступных заданий из репозитория; браузерная проверка прошла без ошибок консоли.
- Пользовательский перенос `APPLICATION_PLAN.md` и других документов в `docs/` сохранён и не включается в функциональный коммит.
- По явному указанию пользователя после F1-I14 нельзя переходить к следующему шагу.
