## Правила для исполнителя

- Перед кодом читать доки Next.js 16 из `node_modules/next/dist/docs/` (breaking changes, см. AGENTS.md).
- Контракты типов из `ARCHITECTURE.md` не менять; если что-то не сходится — остановиться и записать вопрос в конец файла задачи.
- После каждой задачи: `npm run lint`, `npm run build`, `npm test` (с TASK-02) должны быть зелёными.
- Каждая задача — отдельный коммит `feat(location): TASK-NN <суть>`.
- Не создавать документацию и комментарии сверх запрошенного.
